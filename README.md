# Live Wallpaper Generator

Веб-приложение на JavaScript и HTML5 Canvas для генерации зацикленных живых обоев, паттернов и процедурных анимаций. Поддерживает экспорт в PNG и видеозапись в MP4 / WebM.

## Возможности

### Режимы размещения
* **Сетка:** Равномерное распределение элементов по холсту с заданным шагом.
* **Шоу дронов:** Волновые эффекты (горизонтальные, радиальные, диагональные).
* **Хаотичный:** Случайное размещение фиксированного количества точек.

### Движение и анимация
* **Статично:** Фиксированная прозрачность 100% без мигания.
* **Мерцание:** Плавное изменение прозрачности элементов.
* **Дрейф:** Колебания элементов по круговой траектории.
* **Полёт:** Направленное движение с переносом через границы холста (направления: произвольно, влево, вправо, вверх, вниз, по диагонали).
* **Шлейфы:** Регулируемый эффект затухания следа (motion blur).

### Настройки внешнего вида
* Выбор цвета фона и элементов (HEX/RGB).
* Формы элементов: круги, квадраты, ромбы.
* Регулировка размера элементов, ширины волны и скорости анимации.

### Экспорт
* **Изображения:** Сохранение текущего кадра в PNG.
* **Видео:** Запись бесшовных петель (4, 6 или 8 секунд) через MediaRecorder API.
* **Разрешение экспорта:** Экранное, 720p, 1080p, 4K.
* **Настройка битрейта:** От 5 до 50 Mbps.
* **Форматы:** WebM и MP4.

## Стек технологий

* HTML5 (Canvas API, MediaRecorder API)
* CSS3
* JavaScript (ES6+)

Для работы приложения не требуются внешние библиотеки, зависимости и сборщики.
